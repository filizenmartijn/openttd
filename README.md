# OpenTTD Nederland Editie (web)

Speel online: **https://filizenmartijn.github.io/openttd/**

OpenTTD 15.3 gecompileerd naar WebAssembly, met:
- OpenGFX2 Classic, en optioneel OpenGFX2 HD (eenmalige download, bewaard in de browser)
- Dutch Trainset 3XL, Dutch Tram Set, Dutch Road Furniture, Dutch Station Addition Set
- Savegames automatisch downloaden bij opslaan, en terugzetten via het menu rechts
- Nederlands en Engels

## Broncode en licentie
OpenTTD, OpenGFX2 en de NewGRFs zijn vrijgegeven onder de GNU GPL v2 (of later); zie `source/COPYING.md`.
De broncode is OpenTTD 15.3 (https://github.com/OpenTTD/OpenTTD/tree/15.3) met de aanpassingen in
`source/openttd-15.3-web-nl.patch`. De bouwinstructies staan in `os/emscripten/README.md` van OpenTTD.
De NewGRFs komen van BaNaNaS (https://bananas.openttd.org) en OpenGFX2 van https://github.com/OpenTTD/OpenGFX2.
